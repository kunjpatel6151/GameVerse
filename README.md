# 🎮 GameVerse

GameVerse is a modern front-end e-commerce website designed for gaming enthusiasts. The website provides an engaging shopping experience for discovering and purchasing games, gaming accessories, and related products.

## 🚀 Live Demo

Visit the live website:
**https://kunjpatel6151.github.io/GameVerse/**

## 📌 Features

- Responsive user interface
- Interactive product listings
- Product categories and navigation
- Shopping cart UI
- Dynamic content using JavaScript and jQuery
- Modern gaming-themed design
- Mobile-friendly layout

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- jQuery
